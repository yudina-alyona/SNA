## Цель работы

Научиться подготавливать и обрабатывать данные, собранные из социальной сети ВКонтакте, а также освоить базовые методы анализа текстовой информации: подсчёт частоты слов (WordCount) и кластеризацию текстов.

## Исходные данные

В качестве исходных данных используется файл `samara_university_august_2026.csv`, полученный в ходе выполнения лабораторной работы №1. Файл содержит 40 постов сообщества Самарского университета за август 2026 года.

## Задание 1. Предобработка данных

**Что сделано:**

1. Загрузка CSV из ЛР1.
2. Удаление постов без текста и дубликатов: было 40, осталось **39** (один пост без текста).
3. Очистка текста:
   - удаление URL и VK-разметки `[url|текст]`;
   - удаление эмодзи и спецсимволов (оставлены только буквы, цифры и пробелы);
   - приведение к нижнему регистру;
   - схлопывание лишних пробелов.
4. Лемматизация с помощью `pymorphy3`.
5. Удаление стоп-слов: NLTK `stopwords('russian')` + список (`наш`, `который`, `это`, `также`, `свой` и др.).

**Результат:** DataFrame `df_clean` с колонкой `tokens` (список лемм для каждого поста).

## Задание 2. Подсчёт частоты слов (WordCount)

**Что сделано:**

- Подсчёт частоты лемм по всему корпусу.
- Сохранение результата в `wordcount.csv` с колонками `word`, `count`.
- Уникальных лемм: **1794**.
- Топ-10 слов: `университет`, `самарский`, `студент`, `проект`, `программа`, `королёв`, `институт`, `новый`, `регион`, `центр`.

**Результат:** `wordcount.csv`.

## Задание 3. Кластеризация текстовых данных

### Подготовка признаков

Построена TF-IDF матрица с параметрами:

```python
TfidfVectorizer(
    max_features=300,
    min_df=2,
    max_df=0.9,
    ngram_range=(1, 1)
)
```

Размер матрицы: **39 × 300**.

### Выбор числа кластеров

`k` подбирался перебором от 2 до 10 с ограничением «минимальный кластер не меньше 2 постов» (защита от вырожденных решений). Оптимальное значение - **k = 8**.

Метрики по KMeans для разных `k` сохранены в `k_selection_metrics.csv`. График обоснования выбора - `k_selection.png`.

### Сравнение алгоритмов при k = 8

| Алгоритм | Силуэт | DB-индек | Распределение |
|---|---|---|---|
| **Agglomerative** | **0.096** | 2.431 | 10 / 6 / 3 / 9 / 3 / 2 / 3 / 3 |
| KMeans | 0.088 | 2.448 | 13 / 4 / 3 / 6 / 3 / 3 / 4 / 3 |
| DBSCAN | 0.056 | 2.861 | −1: 5, 0: 22, 1: 6, 2: 3, 3: 3 |
| MiniBatchKMeans | −0.024 | 2.184 | 1 / 2 / 19 / 1 / 9 / 3 / 3 / 1 |

**Вывод:** наилучший результат показал **агломеративный алгоритм** (силуэт 0.096). KMeans дал близкое качество (0.088). MiniBatchKMeans на корпусе из 39 документов не сходится (отрицательный силуэт, 19 документов в одном кластере). DBSCAN склонен к увеличению кластеров и выделению шума.

### Визуализация

- `clusters_pca.png` - 4 графика (по одному на алгоритм) в 2D-проекции PCA. Для обозначения кластеров использованы разные геометрические маркеры.
- `clusters_tsne.png` * визуализация t-SNE для KMeans.

Кластеры частично перекрываются, что согласуется с низкими значениями силуэта и объясняется малым объёмом данных и тематической близостью публикаций.

## Результаты

- `wordcount.csv` - частотный словарь (1794 уникальных леммы).
- `clustering_results.csv` - распределение 39 документов по кластерам для 4 алгоритмов.
- `cluster_top_terms.csv` - топ-10 слов по каждому кластеру KMeans.
- `k_selection_metrics.csv` - силуэт, DB-индекс и минимальный размер кластера для `k` от 2 до 10.
- `k_selection.png` - обоснование выбора `k = 8`.
- `clusters_pca.png`, `clusters_tsne.png` - визуализация кластеров.

## Ограничения

- Данных мало (39 документов), поэтому силуэтные коэффициенты низкие (0.02–0.10).
- MiniBatchKMeans не сходится на малом объёме данных.
- DBSCAN крайне чувствителен к параметру `eps`; на разреженных TF-IDF-данных он даёт либо один крупный кластер, либо много микро-кластеров.
